# Gumroad Auditor Enterprise

This project is a comprehensive suite of tools for Gumroad creators. It provides AI-powered audits, smart pricing suggestions, social media content generation, and more.

## Features

*   **AI Audits:** Get AI-powered feedback on your Gumroad products.
*   **Smart Pricing:** Receive intelligent pricing recommendations.
*   **Social Media Generator:** Automatically create social media posts for your products.
*   **Email Suite:** Generate email campaigns to engage your audience.
*   **QR Codes:** Create QR codes to promote your products.
*   **Funnel Analytics:** Analyze your sales funnel to identify areas for improvement.
*   **PDF Export:** Export your product data to a PDF report.

## How to Use

1.  Open the `Gumroad Auditor Code Issues and Fixes.html` file in your web browser.
2.  Enter your Google Gemini API key and Gumroad access token.
3.  Import your Gumroad products by pasting the JSON response from the Gumroad API.
4.  Use the various tools to audit your products, generate content, and analyze your sales.

## Files

*   `Gumroad Auditor Code Issues and Fixes.html`: The main file for the application.
*   `.idx/dev.nix`: A development environment configuration file.
